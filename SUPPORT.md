# Support

Wardoff currently offers **community support only**.

## Community support

- Use **GitHub Discussions** for questions, usage help, and general feedback.
- Use the repository's **issue forms** for reproducible bugs, compatibility reports, documentation issues, and feature requests.
- Use **`SECURITY.md`** for private vulnerability reporting guidance. Do not post security details publicly.

## Current limits

- There is **no paid support, consulting, SLA, or priority-support offering active today**.
- If signed binaries are offered later, that will be a convenience purchase and not a support entitlement.
- Wardoff remains source-first for technical early adopters; support expectations should stay aligned with that scope.
